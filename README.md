## Featured Projects

### Air Quality and Health Prediction

A machine learning project analyzing the relationship between air quality indicators and hospital admissions.

**Tools:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn  
**Methods:** Data cleaning, EDA, feature engineering, regression modeling, model evaluation  

[View Project](https://github.com/suontrunggg/air-quality-health-prediction)

---

### Student Performance Analytics Dashboard

An interactive Streamlit dashboard for analyzing student academic performance using demographic, study habit, and behavioral variables.

**Tools:** Python, Streamlit, Pandas, Plotly  
**Methods:** Interactive dashboard, data filtering, KPI cards, exploratory data analysis  

[View Project](https://github.com/suontrunggg/student-performance-analytics-streamlit)

---

### Vietnam Spatial Economic Analysis

A spatial econometrics project exploring economic relationships between Vietnamese provinces using Moran's I and spatial regression models.

**Tools:** Python, GIS, Spatial Econometrics, Data Visualization  
**Methods:** Moran's I, LISA, SEM-FE, SAR-FE, SDM-FE
